A nomenclatura atual diferencia objetivamente:

- `16_9`: composição em proporção horizontal 16:9;
- `9_16`: composição em proporção vertical 9:16;

- `modelo`: versão identificada como modelo;

Este documento não cria finalidades adicionais que não estejam estabelecidas pelos próprios ativos ou por decisão posterior do projeto.

## 3. Uso e preservação

Regras:

- utilizar a proporção adequada ao contexto em que o vídeo for empregado;
- não recortar uma variante para simular outra proporção quando existir arquivo específico;
- não renomear silenciosamente os arquivos após começarem a ser referenciados por documentação ou implementação;
- não gerar variantes claras, novas proporções ou novas composições sem necessidade documentada;
- preservar os arquivos originais como referência do conjunto atual.

Se novas versões forem adicionadas, este catálogo deve ser atualizado para indicar sua finalidade e relação com as versões existentes.
